# Security Policy

## Reporting Security Vulnerabilities

We take the security of Gih and your Git repositories seriously. If you discover a security vulnerability or believe you have found an issue that affects repository integrity, credential handling, or process execution safety, please let us know immediately.

### How to Report

Please **do not** report security vulnerabilities via public GitHub issues.

Instead, please send an encrypted or direct email detailing the vulnerability to:

**natelligence.ai@gmail.com**

Please include:
- A description of the issue and potential impact.
- Steps to reproduce the issue (including any specific Git commands or repository states).
- Your operating system and environment details (e.g., Windows version, Node.js version, Git version).

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
